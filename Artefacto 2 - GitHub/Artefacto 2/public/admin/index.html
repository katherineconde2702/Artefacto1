Cómo se calcula el descuento
  1. Se parte de la tarifa de la zona.
  2. Se cuentan pedidos confirmados de esa zona, fecha y franja.
  3. Se aplica un único escalón: el mayor umbral alcanzado.
  4. Se compara con la promoción manual y se usa el menor precio.
  5. Se respeta el mínimo de envío. Las reservas aceptadas conservan su precio.
